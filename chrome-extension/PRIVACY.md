# Answer Clipper Privacy Policy

Last updated: August 14, 2026

Answer Clipper has one purpose: to let users select text on ChatGPT, add an annotation, and save that content on their own device.

## Data handling

- The extension processes text intentionally selected by the user, annotations, categories, tags, the ChatGPT page title and URL, and the save time.
- This data is stored only in the extension's local Chrome storage, a Markdown file explicitly selected by the user, or a Markdown file explicitly downloaded by the user.
- The extension has no server, sends no network requests, calls no AI model, and does not sell, share, or upload user data.
- The extension does not read conversation content that the user has not intentionally selected.

## Permission use

- `storage`: Stores the local annotation inbox, default file name, and related local settings.
- `downloads`: Creates Markdown downloads when the user chooses **Save as Markdown** or **Export all**.
- Access to `chatgpt.com` and `chat.openai.com`: Detects intentional text selections and displays the annotation interface.

## Data deletion

Uninstalling the extension removes the extension data stored by Chrome. Markdown files already written or downloaded to the user's device are not affected and can be deleted by the user at any time.

## Contact

For privacy questions, contact the maintainer through the project's GitHub Issues page.
