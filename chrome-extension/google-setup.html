Google Docs setup

This is a one-time setup for the extension's maintainer. After an OAuth client is configured in the build, users only need to select Connect Google and authorize their account.

Configure your Google app

  1. Open the Google Cloud console, choose your project, and enable the Google Docs API.
  2. Configure Google Auth Platform branding and audience. During testing, add your Google account as a test user.
  3. Add the scope https://www.googleapis.com/auth/documents. This is a sensitive scope; public distribution requires Google's applicable verification.
  4. Create an OAuth client of type Chrome Extension with the extension ID shown on its card in chrome://extensions.
  5. From the repository root, run node scripts/configure-google-oauth.mjs YOUR_CLIENT_ID.apps.googleusercontent.com.
  6. Reload Answer Clipper in chrome://extensions, reopen Settings, and select Connect Google.

No client secret or API key is needed. Keep the extension ID stable; the OAuth client must match the loaded extension.

Choose where notes go

Paste an existing Google Docs link, including its tab parameter if needed, or create a document from Settings. Choose Google Docs in the annotation's Save to selector and click Save, or select Export Inbox to Google Docs to send the collected notes together.

Local copies remain available if Google is offline or permission expires. Repeated exports skip annotations already added to the selected tab, unless their tracking ranges were removed by edits in Google Docs.
